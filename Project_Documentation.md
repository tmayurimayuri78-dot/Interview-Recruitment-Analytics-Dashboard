INTERVIEW RECRUITMENT ANALYTICS DASHBOARD
=========================================

1. PROJECT OVERVIEW
-------------------
The Interview Recruitment Analytics Dashboard is an end-to-end data analytics project developed using MySQL, Microsoft Excel, and Power BI. The project analyzes the recruitment process by tracking candidate performance, interview results, skill assessments, and selection trends. The dashboard provides interactive visualizations to support data-driven recruitment decisions.

2. PROBLEM STATEMENT
--------------------
Recruitment teams often manage large amounts of candidate data, making it difficult to identify hiring trends and evaluate candidate performance. This project addresses that challenge by transforming raw recruitment data into meaningful insights using interactive dashboards.

3. PROJECT OBJECTIVES
---------------------
• Analyze candidate recruitment data.
• Measure candidate selection and rejection rates.
• Compare candidate skill performance.
• Evaluate interview round scores.
• Analyze college-wise recruitment trends.
• Provide interactive dashboards for recruitment analysis.

4. TOOLS & TECHNOLOGIES
-----------------------
Database      : MySQL
Data Cleaning : Microsoft Excel
Visualization : Microsoft Power BI
Language      : SQL

6. DATA ANALYSIS PROCESS
------------------------
Step 1 : Designed the MySQL database.
Step 2 : Created four relational database tables.
Step 3 : Imported recruitment datasets into MySQL.
Step 4 : Cleaned and validated data using Microsoft Excel.
Step 5 : Imported data into Microsoft Power BI.
Step 6 : Created relationships between tables.
Step 7 : Built DAX measures for KPIs.
Step 8 : Designed interactive dashboards with charts and slicers.
